#Streaming Site Analyser
A practice project for Pandas

#Features
- Analyse number of movies vs. tv shows
- Print the year with the most releases
- Histogram showing how many titles were released in each year range

#Concepts Learned
- .Series(), .DataFrame(), .read_csv, .read_json
- .value_counts()
- mean(), median(), and mode()
- Basic correlations
- Basic plotting and graphing
